# data/jkp

Generated by `Python/market_data/global_factor_*.py` (run from repo root, in order):

1. `global_factor_download.py --user <wrds_username>` -> `all.parquet`
   WRDS JKP global factor characteristics, US, 2018-05-01..2025-12-31, one row per stock per month-end, all columns.
2. `global_factor_returns.py` -> `factor_returns_daily.parquet` (153 daily factor returns, public, no login), `mkt_daily.parquet`
3. `global_factor_reduce.py` -> `reduced.parquet` (id/return columns + 20 picked factors),
   `picked_factors.csv`, `pca_top20.csv` (lambda, % explained), `factor_returns_reduced.parquet`

4. `global_factor_cov_stats.py` -> `cov_cube.npz` (153 x 153 x N rolling daily covariance), `cov_full.csv`,
   `factor_stats.csv` (per-factor stats), `pca_all.csv` (all 153 eigenvalues)

Steps 2, 3's picking and 4 can run before WRDS access; step 3 needs `all.parquet` only for the last write.

- `factor_meta.csv`: the 153 factors (cluster, description, direction, original paper), from the official JKP `Factor Details.xlsx`.
- `column_dictionary.csv`: meaning of every column in `all.parquet`.
- Factor returns are signed: (top tercile - bottom tercile) x direction.
- Characteristic at `eom` = t pairs with `ret_exc_lead1m` (return in month t+1).
- `all.parquet`, `cov_cube.npz` and `raw/` are git-ignored (too large for GitHub); everything else can be committed.
- `reduced.parquet` has an `in_sp500` flag (ticker match against data/universe/sp500_universe_early_end.csv).
